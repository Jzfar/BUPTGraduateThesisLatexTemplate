# 修改内容及说明

根据评阅专家关于论文创新性论证、时序动态性分析、数据集局限性、主体识别方式及图表可读性的意见，经研究生与导师进一步讨论，对论文进行了针对性修改。具体修改内容及原因如下：

1. 针对“主要创新点陈述和模型对比验证不够充分”的意见，在第1章补充关键创新性工作概括，并在第4章、第5章原有对比实验和消融实验分析中补充模型设计与实验结果的对应说明，突出组感知融合、主体标识特征、门控融合、路径上下文、顺序编码和交互类型编码的作用。修改原因是增强论文主要创新点和技术优势的可证实性，使创新价值能够更清晰地体现在已有实验结果和方法分析中。

2. 针对“评论传播时序动态性和在线动态预测机制说明不足”的意见，在第4章和第5章从系统功能定位角度补充说明本文系统面向离线传播价值评估、排序筛选和结果展示，当前不承担实时热度追踪、流式监测或预测结果滚动更新功能，因此模型实现采用静态特征和固定窗口标签；同时在第7章未来工作中集中补充时序动态性对内容传播的重要影响，并提出动态时序建模、时间窗口特征、点过程模型、时序图模型和在线学习等可能方向。修改原因是明确本文系统功能边界，并给出面向实时传播监测场景的后续改进路径。

3. 针对“数据集覆盖面有限”的意见，在第4章和第5章补充数据集局限性分析，明确数据来源为X平台，AI主体主要为Grok，Human与Agent样本分布不均衡，实验结论主要适用于当前平台和主体设定；在第7章补充跨平台、多AI主体和更均衡采样的未来扩展方向。修改原因是明确实验结论的解释边界和泛化条件。

4. 针对“主体识别依赖人工标注或账号ID”的意见，在第7章未来工作中补充自动化主体识别可行性分析，提出可结合账号元数据、活跃节律、内容风格、语言特征、互动网络结构和多模态资料等信号，并探索弱监督或半监督识别方法。修改原因是回应系统通用性限制，并说明后续从主体自动识别到传播影响力评估的改进方向。

5. 针对“图文内容和图表可读性需核实优化”的意见，对本次修改涉及的第4章、第5章和第7章内容进行了校对，重点检查章节结构、图表引用、图表呈现和编译输出。修改原因是保证论文内容表达规范、图表显示清晰，提升论文整体规范性和可读性。

以上修改均为根据评阅意见和导师指导对论文内容进行的优化完善，不涉及新增图表或公式。
