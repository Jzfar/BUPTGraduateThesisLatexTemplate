# 修改内容及说明

根据评阅专家关于论文关键创新性工作、模型对比验证和技术优势阐述不够充分的意见，经研究生与导师进一步讨论，对论文相关章节进行了针对性修改。具体修改内容及原因如下：

1. 在第1章“本文研究内容”部分补充论文关键创新性工作的概括说明，进一步明确本文围绕主体感知的评论传播价值评估、交互感知的路径传播延续预测以及数据、模型、系统验证链条开展研究。修改原因是根据评阅意见增强主要创新点的系统性陈述，使论文关键创新性工作更加清晰。

2. 在第4章“基于组感知融合的评论传播价值评估模型”中，结合已有整体对比实验、分主体实验和消融实验，对Group-aware Fusion TabTransformer模型的技术优势进行补充说明，突出主体标识特征组、样本级门控融合机制和组级建模在多主体传播价值评估中的作用。修改原因是根据评阅意见进一步说明所提模型相较于LR、XGBoost、TabTransformer、AutoInt等基线方法的有效性和适用场景。

3. 在第5章“基于交互感知的异构路径传播延续预测模型”中，结合Node-Only、Mean Pooling、LSTM、Transformer、Bi-LSTM和消融实验结果，补充说明路径上下文、节点顺序关系和交互类型编码对传播延续预测的贡献。修改原因是根据评阅意见进一步强化IHPE模型的可证实技术优势，说明其并非单纯增加模型复杂度，而是针对多主体路径传播场景进行结构化建模。

4. 对第4章和第5章的章节小结进行了相应调整，使实验结果、模型设计和技术优势之间的逻辑关系更加连贯。修改原因是根据评阅意见提升论文对主要创新点的系统性和清晰性，同时保持硕士论文实验分析部分的行文规范。

以上修改均为根据评阅意见和导师指导对论文内容进行的优化完善，不涉及新增图表或公式。
